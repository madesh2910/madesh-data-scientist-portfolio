# Madesh P — Data Scientist Portfolio

Premium React + Vite portfolio for **Madesh P — Aspiring Data Scientist | Machine Learning Enthusiast**.

## Run in VS Code

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. In Vercel, import the repository.
3. Framework: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

`vercel.json` is included for the build/output settings.

## Deploy to Netlify

Build command: `npm run build`

Publish directory: `dist`

`netlify.toml` is included.

## GitHub

```bash
git init
git add .
git commit -m "Build premium Data Scientist portfolio"
git branch -M main
git remote add origin https://github.com/madesh2910/madesh-portfolio.git
git push -u origin main
```

If the repository already exists locally, use its existing remote instead of adding another one.
